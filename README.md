# Typing Game Web Application

## Description
A typing game web application to develop your typing skills. Practice by: Typing quotes, most common English words, or Versus mode.\
This is a personal project focusing on developing my full-stack development skills, particularly skills in web application architecture, backend development, and multiplayer functionality through WebSockets. 
I am using Java and Spring Boot, with JavaScript, CSS and HTML for the frontend.
